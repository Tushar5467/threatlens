# Project Checklist

A. Model comparison (not just one model)
B. Proper evaluation (macro-F1, PR-AUC, Recall@K, MRR, anomaly precision/recall)
C. Explainability (SHAP + retrieved evidence)
D. Deployment (public link, upload an input, see it work)
E. Documentation (problem, dataset attribution, architecture diagram,
   model comparison, results, screenshots, install steps, limitations)

Rule: no accuracy claims without real experiments.
